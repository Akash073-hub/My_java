# 🔐 Encapsulation in Java

This folder demonstrates how to hide data and protect it using:
- private variables
- getters
- setters

## 🌟 What Is Inside?

### ✔ Programs showing:
- Private fields inside classes
- Controlled access using getters/setters
- Validation inside setters (ex: age > 0)
- Encapsulated Student, Employee, Product examples

## 🔸 Why Encapsulation?
- Protects sensitive data  
- Prevents direct modification  
- Used in all real world apps (Bank balance, passwords, profile data)

🔒 This folder teaches how to build **secure and maintainable code**.
