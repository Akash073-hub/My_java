# ⚠️ Exception Handling

This folder contains programs about managing errors in runtime safely.

## 🌟 Concepts Covered

### ✔ try-catch-finally
### ✔ throw & throws
### ✔ Custom Exceptions
### ✔ Handling multiple exceptions
### ✔ NumberFormatException, ArrayIndexOutOfBounds, etc.

## 🔸 Why Learn This?
Exception handling makes your program:
- stable
- crash-free
- user-friendly

Real life example:
- ATM card wrong PIN attempt  
- Online form invalid input  
- Divide-by-zero protection
