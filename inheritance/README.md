# 🧬 Inheritance in Java

This folder teaches how classes reuse properties of other classes.

## 🌟 Types Covered
✔ Single Inheritance  
✔ Multi-level Inheritance  
✔ Hierarchical Inheritance  

## 🌟 Topics Included
- super() keyword
- Constructor chaining
- Method overriding

## 🔸 Real Life Examples
- Person → Employee → Manager  
- Vehicle → Car → ElectricCar  
- Loan → HomeLoan / PersonalLoan

A very important OOP topic, essential for real-world applications.
