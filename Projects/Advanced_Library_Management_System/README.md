<h1>📚 Advanced Library Management System</h1>

<p>A simple Java project demonstrating <b>OOP, Inheritance, Interfaces, Abstract Classes, Collections, and Custom Exceptions</b>.</p>

<h2>✨ Features</h2>
<ul>
    <li>Add, issue, and return books</li>
    <li><b>Book → LibraryBook</b> (Inheritance)</li>
    <li>Implements <b>Printable</b>, extends <b>LibraryAction</b></li>
    <li>Custom Exceptions:
        <ul>
            <li>BookAlreadyIssuedException</li>
            <li>InvalidPriceException</li>
        </ul>
    </li>
    <li>Uses <b>List</b>, <b>Set</b>, <b>Map</b>, <b>TreeMap</b>, <b>Iterator</b></li>
</ul>

<h2>🏗️ Concepts Used</h2>
<ul>
    <li>Classes & Objects</li>
    <li>Constructor chaining (<code>super()</code>)</li>
    <li>Abstraction + Interface</li>
    <li>Collections Framework</li>
    <li>Exception Handling</li>
</ul>
