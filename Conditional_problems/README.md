# Conditional_problems

# 🔍 Conditional Problems

This folder contains programs based on **decision-making statements** like:
- if
- if-else
- nested if-else
- switch-case

## 🌟 What Is Covered?

### ✔ Real-life style logic such as:
- Check voting eligibility
- Find largest of 3 numbers
- Grade calculation
- Leap year check
- Calculator using switch-case
- Character identification (vowel, digit, alphabet)

### ✔ Why Learn This?
Conditional statements are the **heart of logic building**.
Every program reacts differently based on decisions —
just like ATM PIN verification, login systems, billing, etc.

### 📘 Importance in Exams
These are must-write questions in **university practicals**, **vivas**,  
and **Java lab internal tests**.
