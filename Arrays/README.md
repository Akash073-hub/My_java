# 📂 Arrays in Java

This folder contains programs related to **Java Arrays**, which are used to store
multiple values of the same type in a single variable.

## 🌟 What You Will Learn Here

### 🔸 1. Declaring & Initializing Arrays
- `int[] arr = new int[5];`
- `int[] arr = {1, 2, 3, 4, 5};`

### 🔸 2. Accessing Elements
- Printing values using loops
- Finding values at specific indexes

### 🔸 3. Array Operations Included in This Folder
✔ Traversing arrays  
✔ Searching elements  
✔ Maximum / Minimum values  
✔ Sum of array elements  
✔ Average of array elements  
✔ Counting even/odd numbers  
✔ Simple DSA-based logic building  

### 🔸 4. Why Arrays Are Important?
- Used in **data structures**, **algorithms**, **matrices**, **sorting**, and **searching**.
- Very commonly asked in **interviews** and **exams**.
- Foundation of **DSA**.
